# Club Planner 0.2.2

Версия добавляет полноценное ручное восстановление стен непосредственно поверх импортированного PDF или изображения и повышает устойчивость локального распознавания.

## Главное

- Review-холст получил zoom-at-cursor, pan на ПКМ/средней кнопке, fit, отдельные слои и регулируемую прозрачность подложки.
- Прямая стена строится непрерывной цепочкой с магнитами к узлам, стенам, пересечениям и линиям исходника; доступны `W`, `Alt`, `Shift`, `Tab`, `Esc` и точный ввод длины.
- Дуга задаётся тремя понятными точками — начало, конец хорды, кривизна — с живыми длиной и радиусом и сохраняется настоящим `bulge`.
- Примыкание к середине существующей стены создаёт общий узел и безопасно делит прямую или дугу; разрез через дверной/оконный проём запрещён.
- `Delete` и кнопка удаления корректно обрабатывают распознанные/ручные стены, связанные проёмы и orphan-вершины. Вся операция отменяется одной командой Undo.
- Worker `local-hybrid-3` возвращает отдельные магнитные guides: слабое свидетельство помогает дочертить план, но не загрязняет архитектуру без явного действия пользователя.
- Прямые ищутся на двух масштабах, узкий фильтр края больше не удаляет наружные стены, а topology-backed одиночные перегородки допускаются только с поддержкой на обоих концах.
- Дуги извлекаются из локальных контуров и уменьшенного Hough-прохода; сильные неполные парные грани могут сформировать автоматическую curved wall. На предоставленной фотографии появилась дуговая стена вместо нуля, а этап дуг ускорен примерно с 30 до 11 секунд.

## Совместимость и обновление

Формат проекта остаётся `.clubplan` v4. Проекты v1–v3 и legacy JSON по-прежнему мигрируют при открытии. Установленная `0.2.1` получает `0.2.2` через подписанный updater после явного подтверждения пользователя; portable EXE обновляется повторным скачиванием.

Основная работа и распознавание полностью локальны. Сеть используется только для отдельной проверки подписанного обновления GitHub Release.
