# Формат `.clubplan` v1

`.clubplan` — UTF-8 JSON с явной версией. Геометрия хранится в метрах; SVG-координаты вычисляются только при отображении и экспорте.

Минимальная структура:

```json
{
  "format": "clubplan",
  "formatVersion": 1,
  "generator": { "name": "Club Planner", "version": "0.1.0" },
  "project": {
    "id": "project-uuid",
    "createdAt": "2026-08-10T00:00:00.000Z",
    "modifiedAt": "2026-08-10T00:00:00.000Z"
  },
  "basePlan": {
    "id": "base-plan-new-measurement",
    "asset": "assets/base_plan_new_measurement.svg",
    "widthM": 62.3612,
    "heightM": 7.283,
    "unitsPerMeter": 377.952755906,
    "sha256": "b3aa3f1edfe4ff58bd10afcb95138cd6f661d537e93d51e751577540841d42d5"
  },
  "canvas": {
    "semanticLayerVisible": true,
    "clearanceWarningsVisible": true,
    "minimumPassageWidthM": 1.0
  },
  "layers": [],
  "objects": [],
  "groups": [],
  "dimensions": [],
  "customTemplates": []
}
```

## Объекты

Объект содержит стабильный `id`, `type`, `kind`, имя, центр `xM/yM`, `widthM/depthM`, угол по часовой стрелке, слой, блокировку, видимость подписи, стиль и необязательные свойства. Произвольные фигуры могут хранить физическую высоту в `heightM`. Типы `door` и `window` формируют проектную часть семантического слоя; дверь дополнительно хранит направление и угол открывания. Ширина, глубина и физическая высота не могут быть меньше 0,1 м. Угол нормализуется к диапазону 0–359°.

## Группы

Группа содержит `id`, имя, минимум два уникальных `objectIds` и флаг `locked`. Один объект может входить только в одну top-level группу. Вложенные группы в v1 запрещены. При загрузке locked-группы блокировка синхронизируется с участниками.

## Размеры и составные шаблоны

`dimensions` хранит постоянные размеры как две точки в метрах, имя и видимость подписи. `customTemplates` хранит локальные для проекта составные шаблоны: относительные смещения и снимки свойств входящих объектов без ID, абсолютных координат и блокировки. При вставке объектам назначаются новые ID, а набор из нескольких объектов создаётся как постоянная группа.

## Что не сериализуется

Выделение, режим редактирования группы, камера viewport, открытое контекстное меню, drag-preview, активная snap-направляющая, текущий кандидат `Tab`, сессии линейки и выравнивания между перегородками и Undo/Redo не являются постоянной частью проекта. Семантические стены, двери и окна базового плана хранятся отдельно в `assets/base_plan_boundaries.json` и проверяются по ID и SHA-256 базового SVG. Сохраняются проектные настройки холста, включая поворот, сетку, привязку, `wallSnapOffsetM`, автоповорот, видимость семантики и предупреждений, `minimumPassageWidthM`, видимость и контраст плана. При чтении более раннего `.clubplan` v1 отсутствующие новые настройки, размеры и шаблоны получают безопасные значения по умолчанию.

## Валидация и запись

- неизвестная будущая версия отклоняется;
- повторяющиеся ID, отсутствующие ссылки и участие объекта в нескольких группах отклоняются;
- повреждённый файл полностью валидируется до замены текущего проекта;
- desktop-запись выполняется через временный файл и атомарную замену;
- явное сохранение отмечает текущую revision как сохранённую и очищает recovery-файл.
