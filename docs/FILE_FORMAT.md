# Формат `.clubplan` v1

`.clubplan` — UTF-8 JSON с явной версией. Геометрия хранится в метрах; SVG-координаты вычисляются только при отображении и экспорте.

Минимальная структура:

```json
{
  "format": "clubplan",
  "formatVersion": 1,
  "generator": { "name": "Club Planner", "version": "0.1.0" },
  "project": {
    "id": "project-uuid",
    "createdAt": "2026-08-10T00:00:00.000Z",
    "modifiedAt": "2026-08-10T00:00:00.000Z"
  },
  "basePlan": {
    "id": "base-plan-new-measurement",
    "asset": "assets/base_plan_new_measurement.svg",
    "widthM": 62.3612,
    "heightM": 7.283,
    "unitsPerMeter": 377.952755906,
    "sha256": "b3aa3f1edfe4ff58bd10afcb95138cd6f661d537e93d51e751577540841d42d5"
  },
  "canvas": {},
  "layers": [],
  "objects": [],
  "groups": []
}
```

## Объекты

Объект содержит стабильный `id`, `type`, `kind`, имя, центр `xM/yM`, `widthM/depthM`, угол по часовой стрелке, слой, блокировку, видимость подписи, стиль и необязательные свойства. Ширина и глубина не могут быть меньше 0,1 м. Угол нормализуется к диапазону 0–359°.

## Группы

Группа содержит `id`, имя, минимум два уникальных `objectIds` и флаг `locked`. Один объект может входить только в одну top-level группу. Вложенные группы в v1 запрещены. При загрузке locked-группы блокировка синхронизируется с участниками.

## Что не сериализуется

Выделение, режим редактирования группы, камера viewport, открытое контекстное меню, drag-preview и Undo/Redo не являются постоянной частью проекта. Сохраняются проектные настройки холста, включая поворот, сетку, привязку, видимость и контраст плана.

## Валидация и запись

- неизвестная будущая версия отклоняется;
- повторяющиеся ID, отсутствующие ссылки и участие объекта в нескольких группах отклоняются;
- повреждённый файл полностью валидируется до замены текущего проекта;
- desktop-запись выполняется через временный файл и атомарную замену;
- явное сохранение отмечает текущую revision как сохранённую и очищает recovery-файл.
