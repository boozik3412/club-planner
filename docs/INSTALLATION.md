# Установка Club Planner на Windows

## Рекомендуемый способ

1. Откройте [страницу последнего релиза](https://github.com/boozik3412/club-planner/releases/latest).
2. В разделе **Assets** скачайте файл `Club-Planner_<версия>_x64-setup.exe`.
3. Запустите файл и завершите установку.
4. Откройте **Club Planner** через меню «Пуск» или ярлык.

Установщик — основной вариант для постоянной работы: он размещает приложение в Windows и позволяет удалить его штатно через «Параметры → Приложения».

## Запуск без установки

Скачайте файл `Club-Planner_<версия>_x64-portable.exe`, поместите его в отдельную папку и запустите. Рядом с portable-файлом не требуется распаковывать дополнительные ресурсы. Пользовательские проекты сохраняются в обычные `.clubplan`-файлы через системный диалог.

## Системные требования

- Windows 10 или Windows 11 x64;
- Microsoft Edge WebView2 Runtime;
- видеодрайвер с WebGL 2 для 3D-режима.

WebView2 уже присутствует на большинстве актуальных Windows 10/11. Если приложение не открывается из-за отсутствия runtime, установите **Evergreen WebView2 Runtime x64** с [официальной страницы Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2).

Основная работа приложения выполняется локально. Интернет требуется только для загрузки приложения, проверки обновлений и, при необходимости, установки WebView2. Недоступность сети не блокирует редактор.

Импорт и распознавание PDF/PNG/JPEG также полностью локальны. PDF.js, OpenCV, Tesseract, WebAssembly-ядро и модели `rus+eng` встроены внутрь EXE; устанавливать Python, Java, OCR-пакеты или соседний sidecar-файл не требуется. Первый запуск импорта может занимать немного дольше из-за инициализации локальных модулей.

## Проверка загруженного файла

В каждом релизе есть `SHA256SUMS.txt`. Для проверки установщика в PowerShell:

```powershell
$version = "0.2.1"
Get-FileHash ".\Club-Planner_${version}_x64-setup.exe" -Algorithm SHA256
```

Полученный SHA-256 должен полностью совпадать со строкой установщика в `SHA256SUMS.txt`.

## Предупреждение Windows SmartScreen

Текущая публичная сборка не подписана коммерческим сертификатом издателя. Поэтому SmartScreen может показать предупреждение «Система Windows защитила компьютер», даже если файл скачан из официального GitHub Release.

Перед продолжением убедитесь, что:

- адрес страницы начинается с `https://github.com/boozik3412/club-planner/releases/`;
- имя файла совпадает с опубликованным в релизе;
- SHA-256 совпадает с `SHA256SUMS.txt`.

Полностью убрать это предупреждение для новых загрузок можно только после приобретения и настройки Windows code-signing сертификата. Проверка хеша подтверждает целостность файла, но не заменяет цифровую подпись издателя.

## Обновление

Начиная с версии `0.1.2`, Club Planner один раз при запуске проверяет подписанный файл обновления в официальном GitHub Release. Если версия найдена, в верхней части боковой панели появляются номер, описание и кнопка **«Установить и перезапустить»**. Установка никогда не начинается без нажатия пользователя.

Проверку можно повторить вручную кнопкой **«Проверить обновления»**. Перед установкой несохранённый проект записывается в recovery, затем показывается прогресс загрузки. Целостность обновления проверяется встроенным публичным ключом Tauri; артефакт с неверной подписью не устанавливается.

Если автоматическое обновление недоступно, закройте Club Planner, скачайте новый установщик со [страницы Releases](https://github.com/boozik3412/club-planner/releases) и запустите его поверх существующей установки. Проекты `.clubplan` не хранятся внутри папки установки и не должны удаляться при обновлении.
