# Club Planner 0.2.7

## Точные углы архитектурных стен

- Для выбранной прямой стены добавлен автовыпрямитель к ближайшему шагу `1°`, `5°`, `15°`, `45°` или `90°`.
- Округление сохраняет длину стены и фиксирует её начальную вершину.
- Поле «Точный угол стены, °» позволяет вручную задать произвольное значение.
- Для дуговой стены сохраняется отдельное редактирование точного угла хорды; автоматическое выпрямление дуги отключено.
- При перетаскивании узла прямой стены направление мягко магнитится к 15-градусной сетке: `Shift` фиксирует магнит, `Alt` временно отключает.
- Изменение общей вершины остаётся одной Undo/Redo-транзакцией и перемещает все подключённые стены без разрыва графа.
