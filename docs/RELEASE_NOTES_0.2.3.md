# Club Planner 0.2.3

Версия устраняет заметную задержку при панорамировании большого плана правой кнопкой мыши, средней кнопкой и сочетанием `Пробел+ЛКМ`.

## Что изменилось

- Промежуточная позиция камеры больше не записывается в корневое React-состояние на каждом событии мыши.
- Частые события перемещения объединяются через `requestAnimationFrame`; за один кадр меняется только композитный CSS `transform` корневого SVG-слоя.
- Итоговая камера синхронизируется с проектом один раз при отпускании кнопки, поэтому добавление предметов в центр видимой области и остальные camera-зависимые функции остаются корректными.
- Удалена дорогая тень, которая пересчитывалась для всего многомегабайтного SVG при каждом сдвиге.
- Сохранены короткое контекстное меню ПКМ, подавление меню после drag, `Shift+ПКМ` для группировки и альтернативные способы панорамирования.
- Добавлены регрессионные тесты со 120 последовательными событиями движения и фактическим выполнением animation frame: до завершения жеста нет React camera-коммитов, а слой получает последнюю позицию курсора и итоговое состояние фиксируется ровно один раз.

## Совместимость и обновление

Формат проекта остаётся `.clubplan` v4. Установленная `0.2.2` получает `0.2.3` через подписанный updater после явного подтверждения пользователя. Portable EXE обновляется повторным скачиванием.

Основная работа и распознавание полностью локальны. Сеть используется только для проверки подписанного обновления GitHub Release.
