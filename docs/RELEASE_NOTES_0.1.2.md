# Club Planner v0.1.2

Обновление автоматической доставки версий и постоянных размеров для Windows 10/11 x64.

## Скачать

- **`Club-Planner_0.1.2_x64-setup.exe`** — рекомендуемый установщик.
- **`Club-Planner_0.1.2_x64-portable.exe`** — запуск без установки.
- **`SHA256SUMS.txt`** — контрольные суммы обоих `.exe`.

## Изменения

- приложение автоматически и по кнопке проверяет официальный GitHub Release;
- найденное обновление показывает версию и примечания, но устанавливается только после явного подтверждения;
- во время загрузки виден прогресс, перед установкой сохраняется recovery-копия несохранённого проекта;
- updater-артефакты подписываются отдельным Tauri minisign-ключом и проверяются приложением;
- постоянный размер выбирается кликом по линии или строке в панели и удаляется клавишей `Delete`;
- фактическая длина размера постоянно видна на холсте.

## Проверка

- 23 frontend test files / 97 тестов;
- TypeScript, ESLint и production build;
- Rustfmt, 3 Rust-теста и Clippy;
- rendered UI-проверка создания, отображения и выбора постоянного размера без console errors/warnings;
- подписанная Tauri Windows build, NSIS installer, portable executable и updater metadata.

Первый updater-aware релиз — `0.1.2`: он сможет автоматически перейти на следующую опубликованную версию. Полный переход `0.1.2 → 0.1.3` станет обязательной release-проверкой следующей версии.

Подробная инструкция: [INSTALLATION.md](INSTALLATION.md).

> Minisign-подпись обновлений защищает канал автообновления, но не является коммерческой Windows code-signing подписью издателя. SmartScreen всё ещё может показать предупреждение для новой загрузки `.exe`.
