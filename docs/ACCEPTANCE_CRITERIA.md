# Критерии приёмки

## Запуск и оболочка

- [x] Приложение запускается отдельным окном из Windows.
- [x] Для основной работы не требуется открывать браузер и не требуется интернет.
- [x] `F5`, `Ctrl+R` и `Ctrl+P` не вызывают браузерных действий.
- [x] Создаётся установщик Windows; команда сборки документирована.

## Базовый план

- [x] Новый проект открывается пустым: без встроенного обмера, стен, проёмов и предметов.
- [x] Старые проекты и legacy-миграции сохраняют совместимый встроенный векторный обмер.
- [x] План нельзя случайно перетащить или изменить как обычный предмет.
- [x] Зум не ухудшает качество линий.
- [x] При повороте на 180° подписи не отображаются вверх ногами.

## Импорт и распознавание планировки

- [x] PDF, PNG и JPEG выбираются системным диалогом; для PDF можно выбрать одну из нескольких страниц.
- [x] Мастер предоставляет ручную обрезку четырьмя углами, поворот и перспективное выравнивание фотографии.
- [x] До анализа обязательны две точки и подтверждённое расстояние; OCR не принимает масштаб автоматически.
- [x] Векторная PDF-геометрия, OpenCV-анализ линий/дуг и Tesseract `rus+eng` работают локально без CDN.
- [x] Анализ выполняется вне UI-потока, показывает этап и прогресс, отменяется без изменения текущего проекта и восстанавливается после ошибки повторным запуском.
- [x] Результат остаётся черновиком `candidate`; высокая/средняя/низкая уверенность показаны зелёным/жёлтым/красным.
- [x] Можно принять или отклонить стену, принять уверенные стены пакетом и повторно проанализировать выделенную прямоугольную область.
- [x] В проверке можно создать прямую двумя и дугу тремя точками, переместить общий узел, задать толщину/высоту/основание и добавить дверь/окно.
- [x] Review-холст поддерживает zoom-at-cursor, pan на ПКМ/средней кнопке, fit, регулируемую подложку и независимые слои кандидатов, принятых/ручных стен, проёмов и магнитных направляющих.
- [x] Ручная прямая показывает preview толщины/длины/угла, принимает точную длину, продолжается цепочкой и магнитится в экранном радиусе с `Alt`/`Shift`/`Tab` и гистерезисом 10/16 px.
- [x] Ручная дуга задаётся как начало → конец хорды → кривизна, показывает длину/радиус и сохраняется настоящим `bulge`.
- [x] Ручная дуга не превращается в кругоподобную major-дугу, создаётся один раз и автоматически выключает инструмент после третьей точки.
- [x] У выбранной дуги перетаскиваются общие конечные вершины и отдельная ручка кривизны; отпускание создаёт одну review Undo-транзакцию.
- [x] Drag-рамка на шаге проверки выбирает все пересечённые прямые и дуговые стены; `Shift` переключает состав, `Delete` обрабатывает всю выборку одной транзакцией.
- [x] Примыкание переиспользует общий vertex либо атомарно делит host wall; разрез через проём запрещён, а Undo восстанавливает всю операцию.
- [x] Выбранную распознанную стену можно скрыть отклонением/удалением, ручную — удалить физически; связанные проёмы и orphan-вершины обрабатываются безопасно.
- [x] После создания проекта доступны detach, split/merge прямых и дуг, длина/угол/радиус и числовые параметры/перемещение/удаление проёма.
- [x] Разделение дуги сохраняет окружность; проёмы переносятся между частями стены и не могут остаться вне host wall.
- [x] OCR-размер можно превратить в постоянный объект линейки; OCR-высота остаётся явным предложением.
- [x] Только `accepted` участвует в 2D-привязках, вычислении помещений, диагностике и 3D.
- [x] Дуги рисуются SVG `A`, привязываются аналитически и сегментируются для 3D с погрешностью хорды не более 0,01 м.
- [x] Отсутствие масштаба, некорректная принятая стена или проём вне принятой стены блокируют завершение; разрывы и низкая уверенность остаются предупреждениями.
- [x] Встроенный исходник и выровненная подложка сохраняются внутри `.clubplan` v4 и восстанавливаются вместе с проектом.
- [x] Версионированный корпус содержит минимум 10 собственных векторных PDF, 10 сканов и 10 перспективных фотографий с ground truth, лицензией и SHA-256.
- [x] `pnpm recognition:benchmark` реально запускает detector/graph на всех 30 эталонах, пишет per-case/aggregate отчёт и является блокирующей частью `pnpm check`.
- [x] На corpus v2 пройдены пороги стен и проёмов: vector F1 1,000; scan F1 0,917 / opening F1 1,000; rectified photo F1 0,884 / opening F1 0,927.
- [x] Ненадёжный результат получает quality-причины, не разрешает пакетное принятие и ограничивает одновременную отрисовку candidate explosion.
- [x] Синтетические тесты подтверждают contour circle fit, отрицательный прямоугольный угол, строгую/расширенную пару дуговых граней и отсутствие автоматической raster-дуги по одиночному слабому свидетельству.
- [ ] Отдельный лицензированный реальный holdout, не совпадающий с предоставленным пользователем локальным планом, остаётся внешним release-доказательством; синтетические тесты его не заменяют.

## Навигация и вставка

- [x] Новый предмет появляется в центре текущей видимой области, а не в центре всего плана.
- [x] Точка вставки учитывает панорамирование, масштаб, поворот холста и размер рабочей области.
- [x] Удержание правой кнопки мыши панорамирует холст; короткий ПКМ сохраняет контекстное меню.
- [x] `Shift + ПКМ` при выборе минимум двух предметов по-прежнему создаёт группу.
- [x] `Ctrl+C` копирует выбранные предметы и целиком выбранные группы во внутренний буфер приложения.
- [x] `Ctrl+V` вставляет независимые дубликаты, выделяет их и фиксирует вставку одной Undo-транзакцией.
- [x] `P` и кнопка «Помещение» создают замкнутый прямоугольник четырьмя общими стенами; live-preview показывает размер, `Shift` создаёт квадрат.
- [x] `D` и кнопка «Дверь» подсвечивают ближайшую допустимую стену/перегородку и ставят дверь в точке клика.
- [x] Дверь на архитектурной стене становится host opening; дверь на предмете-перегородке атомарно заменяет исходник двумя частями и дверным предметом.

## Множественное выделение

- [x] `Shift + левый клик` добавляет объект к выборке.
- [x] Повторный `Shift + левый клик` убирает объект из выборки.
- [x] Клик по пустому месту снимает выборку.
- [x] Панель показывает количество выбранных объектов.
- [x] Перетаскивание одного выбранного объекта перемещает всю выборку на одинаковое расстояние.
- [x] Undo возвращает всю выборку одним действием.

## Произвольные фигуры

- [x] Можно создать прямоугольник, круг и овал.
- [x] Для фигур редактируются ширина, глубина и физическая высота.
- [x] Круг сохраняет равные ширину и глубину при изменении размера.

## Архитектурные высоты и 3D

- [x] `.clubplan` v4 хранит project-owned архитектурный граф, источники, высоту и отметку установки каждого предмета; v1–v3 автоматически мигрируют без потери объектов.
- [x] Высота базовой стены определяется из обмера/высотной зоны, а отсутствующая толщина получает явно помеченный расчётный fallback.
- [x] Высоту, толщину и отметку основания выбранной стены можно изменить и вернуть одной операцией Undo/Redo.
- [x] Принятые импортированные стены после создания проекта видны поверх подложки как контрастная геометрия физической толщины; капитальные стены и перегородки различимы.
- [x] Стена имеет широкую экранно-стабильную область выбора, заметную подсветку и две ручки незаблокированных концов.
- [x] Перетаскивание общей вершины показывает live-preview, меняет все подключённые стены и фиксируется одной Undo/Redo-транзакцией; отмена pointer gesture не меняет проект.
- [x] Подложка доступна с верхней панели, а новый импорт использует приглушённую начальную прозрачность.
- [x] Пользовательская перегородка получает текущую высоту стен по умолчанию и сохраняет её в проекте.
- [x] Режимы `2D`, `3D` и `2D + 3D` используют одно состояние проекта и не создают второй WebView.
- [x] В 3D видны пол, стены с дверными/оконными проёмами, двери, окна и схематичные объёмы предметов.
- [x] Работают камеры, фокус на выбранном, скрытие стен/потолка и горизонтальное сечение.
- [x] Выделение предметов и стен синхронизировано; предметы с диагностическими предупреждениями выделяются цветом.
- [x] 3D-модуль загружается отдельно от стартового 2D bundle, не использует сеть/CDN и корректно сообщает об отсутствии WebGL 2.
- [x] Высотная схема документирована как обзорная, без заявления о BIM-точности или восстановлении скатов без разрезов.

## Привязка и выравнивание

- [x] При drag грань предмета притягивается к стене базового плана или пользовательской перегородке.
- [x] Множественная выборка при привязке получает один общий вектор и сохраняет взаимные расстояния.
- [x] Активная стена и линия привязки видимы во время drag; `Alt` временно отключает привязку.
- [x] Preview полупрозрачен и показывает тип привязки и числовой отступ.
- [x] `Tab`/`Shift+Tab` переключает близкие кандидаты «к стене», «центр», «угол» и «параллельно».
- [x] Отступ от стены задаётся в метрах; автоповорот мебели и перегородок настраивается отдельно.
- [x] Выборку можно центрировать между двумя параллельными перегородками через preview и Apply/Enter.
- [x] Несколько предметов можно распределить между перегородками с равными промежутками.
- [x] Один прямоугольный предмет можно явно растянуть командой «Заполнить проём» с заданным отступом.
- [x] Отмена/Esc не меняет проект, а применение создаёт одну запись Undo.
- [x] Непараллельные границы и нехватка места не применяют некорректную геометрию.
- [x] Два совпадающих по количеству и интервалам ряда похожих предметов совмещаются общей горизонтальной, вертикальной или диагональной осью.
- [x] При совмещении рядов видны длинная направляющая, маркеры центров и надпись «Ряды на одной линии»; предметы вне текущей видимой области не участвуют.
- [x] Приоритет привязок соблюдает порядок `стена → ряд → объект → сетка`, а `Alt` отключает и эту привязку.

## Массовое редактирование

- [x] Два стола шириной 1,20 м после ввода 1,30 м становятся каждый шириной 1,30 м.
- [x] Если ширины различны, поле показывает mixed-state.
- [x] Новое значение из mixed-state применяется каждому объекту.
- [x] Кнопка +90° поворачивает каждый объект относительно его текущего угла.
- [x] Поле абсолютного угла задаёт одинаковый абсолютный угол каждому объекту.
- [x] Выборка отражается слева-направо и сверху-вниз относительно общего центра; подписи остаются читаемыми, повторное отражение возвращает исходную геометрию.
- [x] Отражение сохраняется в `.clubplan`, SVG и PDF и отменяется/повторяется одной транзакцией.

## Перегородки и проходы

- [x] Одну выбранную незаблокированную перегородку можно разделить центральным проходом заданной ширины.
- [x] Обе части имеют исходные высоту, толщину, угол, слой и стиль, остаются редактируемыми и сохраняют членство исходной группы.
- [x] Команда не создаёт часть короче 0,10 м и целиком отменяется/повторяется одним Undo/Redo.

## Горячие клавиши

- [x] `Ctrl+Z`, `Ctrl+Shift+Z`/`Ctrl+Y`, `Ctrl+G`, `Ctrl+Shift+G`, copy/paste, блокировка, линейка, fit и режимы вида работают при русской и английской раскладках.
- [x] Полный список команд доступен в сворачиваемой справке, а сочетания не запускают команды редактора внутри полей ввода.

## Группы

- [x] `Shift + правая кнопка` группирует два и более выбранных объекта.
- [x] `Ctrl+G` выполняет то же действие.
- [x] Один клик по элементу группы выбирает группу.
- [x] Перемещение группы сохраняет взаимное расположение элементов.
- [x] Поворот группы сохраняет расстояния до общего центра.
- [x] `Ctrl+Shift+G` разгруппировывает.
- [x] После сохранения и повторного открытия состав и геометрия групп сохраняются.
- [x] Undo/Redo корректно работает для группировки и разгруппировки.

## Файлы

- [x] Проект сохраняется в `.clubplan`.
- [x] Проект открывается без потери объектов, размеров, углов и групп.
- [x] Ошибочный или повреждённый файл показывает понятное сообщение и не уничтожает текущую работу.
- [x] Автосохранение не заменяет явное сохранение без уведомления пользователя.
- [x] `.clubplan` v4 — безопасный ZIP-контейнер; проекты v1–v3 автоматически открываются с безопасными значениями и сохраняются как v4.
- [x] Небезопасные ZIP-пути, дубликаты, превышение лимитов, отсутствующий источник и неверный SHA-256 отклоняются до замены текущего проекта.
- [x] Экспорт PDF создаёт валидный одностраничный векторный документ без сети и учитывает текущую видимость слоёв, сетки и подписей.
