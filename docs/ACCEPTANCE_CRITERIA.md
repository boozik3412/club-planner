# Критерии приёмки

## Запуск и оболочка

- [ ] Приложение запускается отдельным окном из Windows.
- [ ] Для основной работы не требуется открывать браузер и не требуется интернет.
- [ ] `F5`, `Ctrl+R` и `Ctrl+P` не вызывают браузерных действий.
- [ ] Создаётся установщик Windows; команда сборки документирована.

## Базовый план

- [ ] При новом проекте автоматически виден актуальный векторный план.
- [ ] План нельзя случайно перетащить или изменить как обычный предмет.
- [ ] Зум не ухудшает качество линий.
- [ ] При повороте на 180° подписи не отображаются вверх ногами.

## Множественное выделение

- [ ] `Shift + левый клик` добавляет объект к выборке.
- [ ] Повторный `Shift + левый клик` убирает объект из выборки.
- [ ] Клик по пустому месту снимает выборку.
- [ ] Панель показывает количество выбранных объектов.
- [ ] Перетаскивание одного выбранного объекта перемещает всю выборку на одинаковое расстояние.
- [ ] Undo возвращает всю выборку одним действием.

## Массовое редактирование

- [ ] Два стола шириной 1,20 м после ввода 1,30 м становятся каждый шириной 1,30 м.
- [ ] Если ширины различны, поле показывает mixed-state.
- [ ] Новое значение из mixed-state применяется каждому объекту.
- [ ] Кнопка +90° поворачивает каждый объект относительно его текущего угла.
- [ ] Поле абсолютного угла задаёт одинаковый абсолютный угол каждому объекту.

## Группы

- [ ] `Shift + правая кнопка` группирует два и более выбранных объекта.
- [ ] `Ctrl+G` выполняет то же действие.
- [ ] Один клик по элементу группы выбирает группу.
- [ ] Перемещение группы сохраняет взаимное расположение элементов.
- [ ] Поворот группы сохраняет расстояния до общего центра.
- [ ] `Ctrl+Shift+G` разгруппировывает.
- [ ] После сохранения и повторного открытия состав и геометрия групп сохраняются.
- [ ] Undo/Redo корректно работает для группировки и разгруппировки.

## Файлы

- [ ] Проект сохраняется в `.clubplan`.
- [ ] Проект открывается без потери объектов, размеров, углов и групп.
- [ ] Ошибочный или повреждённый файл показывает понятное сообщение и не уничтожает текущую работу.
- [ ] Автосохранение не заменяет явное сохранение без уведомления пользователя.

## Регрессия существующих функций

- [ ] Масштабирование и панорамирование работают.
- [ ] Поворот холста работает.
- [ ] Одиночный предмет можно перемещать, изменять в размере и вращать.
- [ ] Работают сетка и привязка.
- [ ] Работают дублирование, удаление, Undo/Redo и экспорт SVG.
