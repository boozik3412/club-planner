# Club Planner v0.1.0

Первая публичная Windows-версия автономного планировщика компьютерного клуба.

## Скачать

- **`Club-Planner_0.1.0_x64-setup.exe`** — рекомендуемый установщик для Windows 10/11 x64.
- **`Club-Planner_0.1.0_x64-portable.exe`** — переносимый запуск без установки.
- **`SHA256SUMS.txt`** — контрольные суммы обоих `.exe`.

## Основные возможности

- точная работа поверх актуального обмерного SVG-плана;
- мебель, оборудование, произвольные прямоугольные, круглые и овальные объекты;
- множественное выделение, группы, Undo/Redo и `.clubplan` v2;
- умное притягивание к стенам и выравнивание между перегородками;
- семантические стены, двери, окна, размеры, проходы и предупреждения пересечений;
- редактируемые высоты стен и предметов;
- локальные режимы `2D`, `3D` и `2D + 3D`;
- обычные файлы проекта, recovery-autosave и экспорт SVG.

## Проверка

- 21 frontend test file / 84 теста;
- TypeScript, ESLint и production build;
- Rustfmt, 3 Rust-теста и Clippy;
- Tauri release build и NSIS installer на Windows x64;
- rendered 2D/3D smoke-test без console errors/warnings.

Подробная инструкция: [docs/INSTALLATION.md](https://github.com/boozik3412/club-planner/blob/main/docs/INSTALLATION.md).

> Сборка пока не подписана коммерческим Windows code-signing сертификатом. SmartScreen может показать предупреждение неизвестного издателя. Загружайте файлы только с официальной страницы релиза и сверяйте SHA-256.
