# Импорт legacy JSON v6

Club Planner открывает `.json` из `legacy/floor_planner_v6_new_base.html`, если корневой объект содержит `version: 6` либо legacy-массив `objects` без поля `format`.

## Переносимые данные

- `canvasAngle` → поворот холста;
- `id`, `type`, `label`;
- `x`, `y`, `w`, `h` → метры центра, ширины и глубины;
- `angle` → нормализованный угол;
- `fill` и `seats`, если они присутствуют.

Поддерживаются legacy-типы `pc1`, `pc2`, `pc5`, `table`, `sofa`, `armchair`, `console`, `reception`, `bar`, `server`, `partition` и `zone`. Неизвестный тип безопасно заменяется на «Свободную зону» с предупреждением.

## Значения, назначаемые при импорте

- слой выбирается по текущему шаблону типа;
- предмет разблокирован;
- подпись видима;
- отсутствующие размеры берутся из текущего шаблона;
- физическая высота и отметка установки берутся из текущего схематичного шаблона;
- архитектурные defaults создаются заново, так как legacy v6 не содержит вертикальной модели;
- повторяющиеся или отсутствующие ID заменяются новыми.

## Ограничения

Legacy v6 не содержит постоянных групп, слоёв, project metadata, checksum базового плана, архитектурных высот и истории. Эти сведения невозможно восстановить и они создаются заново. После импорта проект считается несохранённым; первое сохранение выполняется в `.clubplan` v2 через «Сохранить как».

Старый технический паспорт не используется для пересчёта геометрии. После импорта ссылка на основу всегда указывает на актуальный `assets/base_plan_new_measurement.svg`.
