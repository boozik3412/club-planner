# Club Planner v0.1.1

Обновление навигации и вставки предметов для Windows 10/11 x64.

## Скачать

- **`Club-Planner_0.1.1_x64-setup.exe`** — рекомендуемый установщик.
- **`Club-Planner_0.1.1_x64-portable.exe`** — запуск без установки.
- **`SHA256SUMS.txt`** — контрольные суммы обоих `.exe`.

## Изменения

- новые предметы и составные шаблоны появляются в центре текущей видимой 2D-области с учётом панорамирования, масштаба и поворота;
- удержание правой кнопки мыши панорамирует холст;
- короткий ПКМ сохраняет контекстное меню, `Shift+ПКМ` — группировку;
- `Ctrl+C` копирует выбранные предметы и полностью выбранные группы во внутренний буфер приложения;
- `Ctrl+V` вставляет независимые дубликаты со смещением и одной Undo-транзакцией.

## Проверка

- 22 frontend test files / 91 тест;
- TypeScript, ESLint и production build;
- Rustfmt, 3 Rust-теста и Clippy;
- rendered UI-проверка вставки в центр масштабированной области без console errors/warnings;
- Tauri Windows build и NSIS installer.

Подробная инструкция: [INSTALLATION.md](INSTALLATION.md).

> Сборка пока не подписана коммерческим Windows code-signing сертификатом. SmartScreen может показать предупреждение неизвестного издателя. Загружайте файлы только с официальной страницы релиза и сверяйте SHA-256.
