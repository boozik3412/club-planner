# Сторонние компоненты и локальная обработка

Club Planner не загружает библиотеки распознавания с CDN. Следующие компоненты входят в Windows-приложение как локальные web assets и загружаются только при импорте:

| Компонент | Назначение | Лицензия |
|---|---|---|
| PDF.js 6.2.108 | чтение, рендеринг и доступная векторная геометрия PDF | Apache-2.0 |
| OpenCV.js 5.0.0 | бинаризация, Hough lines/circles и обработка растра | Apache-2.0 |
| Tesseract.js 7.0.0 | локальный OCR worker | Apache-2.0 |
| tesseract.js-core 7.0.0 | WebAssembly-ядро Tesseract | Apache-2.0 |
| `rus`/`eng` traineddata 4.0.0 best | языковые модели OCR | Apache-2.0 |
| Tauri 2 | Windows-оболочка, файлы и updater | Apache-2.0 / MIT |
| React, Vite, TypeScript | интерфейс и сборка | MIT / MIT / Apache-2.0 |
| three, React Three Fiber | схематичная 3D-визуализация | MIT |
| zip, sha2, base64 (Rust crates) | `.clubplan` v4 и контроль целостности | MIT / Apache-2.0 совместимые лицензии согласно lock-файлу |

Полный перечень транзитивных версий зафиксирован в `pnpm-lock.yaml` и `src-tauri/Cargo.lock`; тексты лицензий распространяются в соответствии с исходными пакетами. Тестовый корпус `tests/fixtures/recognition/{vector,scan,photo}` является собственным синтетическим набором CC0-1.0. Реальный `assets/measurement_plan.pdf` не входит в CC0-корпус.

Чертежи, изображения, распознанный текст и архитектурный граф не покидают устройство. Единственный сетевой запрос штатного приложения — отдельная проверка подписанного обновления на официальном GitHub Release; её недоступность не мешает редактору или распознаванию.
