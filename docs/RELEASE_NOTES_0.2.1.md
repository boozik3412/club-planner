# Club Planner 0.2.1

Локальный кандидат выпуска с безопасным распознаванием `local-hybrid-2`.

## Что изменилось

- красные пометки, мелкие текстовые компоненты и регулярная штриховка отделяются от геометрии стен;
- синие условные обозначения дверей/окон обрабатываются отдельно от архитектурных штрихов;
- raster-стена требует двух согласованных граней, T/L/X-стыки образуют общий топологический граф;
- части стены по сторонам двери объединяются в один host wall с редактируемым проёмом;
- общий raster-поиск окружностей больше не создаёт двери, одиночная дуга не принимается за стену, поиск raster-дуг по умолчанию выключен;
- review показывает качество результата, причины риска и блокирует пакетное принятие ненадёжного графа;
- candidate explosion ограничивается 120 видимыми наиболее уверенными элементами;
- corpus v2 и `pnpm recognition:benchmark` проверяют 10 vector PDF, 10 сканов и 10 выровненных фотографий как обязательную часть `pnpm check`.

## Измеренный синтетический gate

- vector PDF, прямые стены: F1 `1,000`;
- scan, прямые стены/проёмы: F1 `0,984` / `1,000`;
- rectified photo, прямые стены/проёмы: F1 `0,938` / `0,950`.

Настоящие raster-дуги и качество на разрешённом реальном holdout ещё не подтверждены. Эти ограничения показаны в проектной документации и не маскируются общей цифрой F1.
