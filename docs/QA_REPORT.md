# Отчёт проверки MVP

Дата: 2026-08-10. Платформа проверки: Windows x64, Rust MSVC, WebView2.

## Автоматические проверки

| Gate | Результат |
|---|---|
| `pnpm typecheck` | пройден |
| `pnpm lint` | пройден без предупреждений |
| `pnpm test` | 8 файлов, 31 тест пройден |
| `pnpm build` | production bundle собран |
| `cargo fmt --check` | пройден |
| `cargo test` | 3 Rust-теста пройдены |
| `cargo clippy --all-targets -- -D warnings` | пройден; локализованное сообщение MSVC linker не является Clippy warning |
| `pnpm tauri build` | release `.exe` и NSIS x64 собраны |

Unit-тесты покрывают базовый asset, камеру, выделение, массовые команды, группировку и поворот вокруг общего центра, историю на 100 операций, serialization/legacy-import и ссылочную целостность. React integration-тест проходит цепочку «два стола → Ctrl+A → ширина 1,3 м → группа → Undo → Redo», проверяет блокировку browser-shortcuts и сохранение текущей работы при повреждённом файле.

## Rendered UI QA

- актуальный план загрузился, найдено 346 групп подписей;
- интерфейс русскоязычный, sidebar прокручивается независимо от холста;
- Ctrl+A выбирает предметы, массовая ширина отображает `1.3`, группировка создаёт одну группу;
- после Undo/Redo выборка снова нормализуется к группе, «Разгруппировать» доступно;
- locked-группа повторно выбирается и может быть разблокирована;
- режим редактирования группы начинает с пустой внутренней выборки и позволяет выбрать один элемент;
- ползунок контраста и значение модели согласованы на `0.82`.

## Нативная Windows-проверка

- release-процесс создаёт отдельное видимое окно с заголовком `Club Planner — планировщик клуба` и отвечает Win32;
- закрытие окна завершает процесс, orphan-процесс не остаётся;
- геометрия окна `1100×680` в позиции `(180, 200)` восстановлена при следующем запуске;
- `.window-state.json` содержит состояние main window;
- системные диалоги подключены официальным Tauri Dialog plugin, а чтение/запись выполняются Rust-командами;
- release binary: 9 539 584 байта, SHA-256 `DAE0B460700D7E57CC50C8195ABA02CF450D07479FB5EB34C58EBCA4CB98E8DA`;
- NSIS installer: 2 191 944 байта, SHA-256 `B4132E0A658236F470ADA7515C6842682B4EFB2BF132E50B8B09652C9951CBFE`.

## Границы проверки

Сборка и запуск проверены на текущей Windows-машине. Отдельная clean Windows 10/11 VM в этой среде недоступна; перед публичной раздачей установщик следует дополнительно прогнать на чистой VM: install → offline launch → create/edit/save → restart/open → uninstall.
