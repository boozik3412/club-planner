# Архитектурное решение: отдельное приложение на Tauri 2

## Решение

Использовать Tauri 2 как настольную оболочку, а интерфейс и редактор реализовать на TypeScript.

## Почему

- текущий прототип уже реализован на HTML/SVG/JavaScript;
- можно переиспользовать векторную планировку, систему координат и часть логики;
- пользователь получает отдельное окно без вкладок, адресной строки и браузерного интерфейса;
- можно использовать системные диалоги открытия/сохранения и обычные файлы проектов;
- итоговая сборка обычно легче Electron;
- приложение может работать без интернета.

## Важное ограничение

Tauri на Windows использует WebView, но это не должно быть заметно пользователю. Необходимо перехватывать и отключать мешающие браузерные команды, включая `F5`, `Ctrl+R`, `Ctrl+P`, стандартное контекстное меню и навигацию боковыми кнопками мыши, кроме тех сочетаний, которым назначены функции редактора.

## Модель данных

Рекомендуется хранить проект как версионируемый JSON с расширением `.clubplan`:

```json
{
  "formatVersion": 1,
  "basePlan": "measurement-v1",
  "canvas": { "rotation": 0 },
  "objects": [],
  "groups": [],
  "settings": {
    "gridVisible": true,
    "gridStepM": 0.5,
    "snapEnabled": true,
    "snapStepM": 0.1
  }
}
```

Группа должна ссылаться на ID объектов, а не дублировать их геометрию. Вложенные группы на первом релизе не обязательны.
