# Club Planner 0.2.4

Версия начинает P0-направление точного и быстрого 2D-редактирования: добавляет верхнюю панель частых инструментов и полноценное изменение уже созданных постоянных размеров.

## Что изменилось

- Над рабочей областью появилась компактная панель Undo/Redo, выбора, панорамирования, линейки, вписывания, сетки, привязок и режимов 2D/3D.
- Добавлены горячие клавиши `V` для выбора и `H` для «Руки»; `M` продолжает запускать линейку.
- Выбранный размер получил ручки начала, конца и переноса всей линии.
- Длина меняется в реальном времени; перенос центральной ручкой сохраняет длину.
- Размеры притягиваются к стенам, проёмам, предметам и сетке. `Shift` фиксирует основную ось, `Alt` временно отключает привязки.
- Стрелки перемещают выбранный размер; `Shift+стрелка` использует шаг 0,01 м.
- Preview размера остаётся локальным и превращается в одну Undo/Redo-транзакцию только после завершения жеста.
- Панель проверена в окнах 1280×720 и 960×640; при узком окне остаются пиктограммы и tooltip.

## Совместимость

Формат `.clubplan` остаётся v4: новые поля проекта не добавлялись. Основная работа и распознавание по-прежнему полностью локальны.

Установленная версия `0.2.3` получает `0.2.4` через подписанный встроенный updater после явного подтверждения пользователя. Portable EXE обновляется повторным скачиванием.
