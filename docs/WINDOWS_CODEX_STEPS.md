# Как открыть пакет в Codex на Windows

1. Распакуйте архив в короткий путь без облачной синхронизации, например:
   `C:\Projects\club-planner`
2. Откройте актуальное настольное приложение ChatGPT и выберите **Codex** в левом верхнем меню.
3. Выберите открытие локальной папки и укажите `C:\Projects\club-planner`.
4. Разрешите Codex читать и изменять только эту папку.
5. Откройте новый поток внутри проекта.
6. Вставьте содержимое `CODEX_START_PROMPT.md`.
7. Для сложной задачи сначала используйте Plan mode (`/plan` или доступный переключатель планирования).
8. После создания `PLAN.md` проверьте план, затем дайте команду начать этап 1.
9. Разрешайте установку зависимостей и команды сборки только после просмотра команды.
10. После появления работающего каркаса инициализируйте Git, если Codex не сделал это раньше, и создавайте контрольные коммиты по этапам.

Не нужно загружать в Codex экспорт всей истории ChatGPT: для разработки важнее файлы, спецификация и исходный прототип из этой папки.
