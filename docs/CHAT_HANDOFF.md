# Краткая история решений из рабочего чата

## Контекст бизнеса

Сеть компьютерных клубов 1337 в Ижевске готовит ребрендинг и перенос точки с улицы Холмогорова, 24А в новое светлое мансардное помещение. Новая площадка отличается от типичных тёмных RGB-клубов: белая архитектура, окна, естественный свет, чёрные металлические конструкции, растения и лаунж-зоны.

## Что уже было сделано

1. Из старого технического паспорта извлекалась планировка.
2. Несколько раз корректировалась ориентация и зеркальное отражение.
3. Был создан браузерный SVG-планировщик.
4. Добавлены поворот холста, сохранение JSON, экспорт SVG, библиотека предметов, изменение размеров и вращение предметов.
5. В качестве новой базы установлен актуальный план из файла замера.
6. Текущая рабочая версия находится в `legacy/floor_planner_v6_new_base.html`.

## Почему требуется настольное приложение

Браузерные горячие клавиши и стандартное поведение браузера мешают работе. Нужна отдельная программа с собственным окном, системным сохранением файлов и управляемыми сочетаниями клавиш.

## Последние продуктовые требования пользователя

- выделять несколько объектов через Shift;
- перемещать выделенные объекты вместе;
- массово менять одинаковые параметры каждого объекта, например ширину каждого выбранного стола;
- связывать выбранные объекты в постоянную группу через Shift + правую кнопку;
- затем использовать группу как единый комплект;
- не переворачивать надписи при развороте холста на 180°;
- сохранять возможность изменять размеры и вращать предметы.
